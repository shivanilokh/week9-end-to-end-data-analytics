# End-to-End Sales Data Analytics Project

## Project Overview

This project demonstrates a complete end-to-end data analytics workflow for analyzing sales performance across products, categories, regions, and time periods.

## Business Problem

The company wants to analyze its sales performance and identify important trends, high-performing products and categories, regional performance differences, and areas requiring improvement.

## Project Objectives

* Analyze overall sales performance.
* Calculate key business performance indicators.
* Identify high-performing products and categories.
* Compare sales performance across regions.
* Analyze monthly sales trends.
* Verify analytical results using multiple tools.
* Create an interactive Power BI dashboard.
* Generate business insights and recommendations.

## Dataset

The dataset contains sales transaction information including:

* Order ID
* Order Date
* Customer Name
* Product
* Category
* Region
* Quantity
* Unit Price
* Discount
* Sales

## Data Cleaning

The dataset was checked for missing values, duplicate records, duplicate Order IDs, incorrect data types, date formats, and inconsistent values.

## Python Analysis

Python and Pandas were used for data loading, data validation, exploratory data analysis, KPI calculation, category analysis, regional analysis, product analysis, and monthly sales trend analysis.

## SQL Analysis

MySQL was used to calculate key business metrics and analyze sales performance by category, region, product, and time period.

## Power BI Dashboard

Power BI was used to create an interactive sales performance dashboard containing:

* Total Sales
* Total Orders
* Total Customers
* Total Quantity
* Average Order Value
* Sales by Category
* Sales by Region
* Monthly Sales Trend
* Top Products
* Interactive Filters

## Business Insights

The analysis identifies important patterns in overall sales performance, category performance, regional performance, product performance, and monthly sales trends.

## Recommendations

The findings can support inventory planning, sales performance monitoring, regional analysis, and data-driven business decision-making.
